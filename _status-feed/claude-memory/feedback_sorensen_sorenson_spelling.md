When researching Charles E. Sorensen (Ford Motor Co. exec, CIC documentary subject) via web search or archive lookups, always run queries for both spellings: "Sorensen" and "Sorenson." His name was commonly misspelled in period press and records.

**Why:** User caught that a batch of web searches (V-8.1a death date, V-8.1b obituary, V-8.2 TPS lineage) only used "Sorensen." Missing the "Sorenson" variant risks silently missing real sources — directly relevant since [[finding-sorensen-transcript-vs-treatment-2026-07-16]]'s item V-8.1c is specifically about whether a documented misspelling instance exists. BFRC's own finding-aid index also surfaced material only via a `keyword=sorenson` search that a `sorensen`-only search missed (see [[decision-xberg-real-extraction-2026-07-16]] session's V-6.5 packet work log, 2026-07-16 entry).

**How to apply:** every future web/archive search for this person runs both spellings as a standing default, not just when specifically hunting for V-8.1c.
