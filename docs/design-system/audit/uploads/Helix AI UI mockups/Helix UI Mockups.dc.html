04 — CLI · Annotated Command Reference
helix.exe — operator shell
# Ask a single question, constrained to IronLedger context
$ helix ask "What changed in the Henderson account this week?" --scope=ironledger
# Open an interactive session pinned to local models only
$ helix chat --model=local
# Print ICF/Sigil connection state, active capabilities, and this session's persistence mode
$ helix status --governance
# Reprint full disclosure — sources, model, lineage, persistence, governance state — for a prior response
$ helix explain <response-id>
