# trm-self-healing

DevOps self-healing triage, research escalation, and Sigil biometric guard skills for Toolforge.

## Quick Start

```bash
node skills/trm-self-healing/src/index.mjs
```

- `trm-tinyfish-triage` — Fast local signature matching and TinyFish search fallback
- `trm-parallel-escalation` — Deep research escalation via Parallel Task API
- `trm-sigil-guard` — Local biometric verification gate over loopback socket
